# NOVAIRE Auto Detailing

A responsive, interactive static website for a Northern Virginia detailing business.

## Files
- `index.html` — page structure and content
- `style.css` — responsive design and animations
- `script.js` — mobile menu, scroll reveals, gallery modal, back-to-top button, quote form demo

## Before launch
1. Replace the placeholder phone/email in `index.html`.
2. Replace the Unsplash gallery/hero URLs with your own photos if desired.
3. Connect `#quoteForm` to a real form service or backend so submissions are delivered.
4. Update prices, service area, FAQ, and package contents.
5. Add your social links and favicon/logo if you have them.
